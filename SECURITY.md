# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security reports.

Report vulnerabilities privately via [GitHub's private vulnerability reporting]
(https://github.com/HedwigDTM/hedwig/security/advisories/new) or contact the
maintainers directly.

Include as much of the following as you can:

- The affected version(s) (`package.json` version or commit hash)
- A description of the vulnerability and its impact
- Steps or a proof of concept to reproduce it

## What to expect

- We will acknowledge your report within a few days.
- We will confirm and assess the report, keep you informed of progress, and
  credit you in the fix release if you wish.
- Fixes ship as a patch release; the advisory is published once a fixed
  version is available.
